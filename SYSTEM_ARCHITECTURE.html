3. Core Subsystem Highlights

  • Authentic 2D Forensic Sketch Engine: Captures the active 3D model at a natural 1:1 square aspect ratio ($d = 0.88\text{m}$), temporarily isolates the silhouette onto pure white paper, and generates multi-pass Sobel edge detection with graphite pencil cross-hatching. Zero artificial vector lines.
  • Antigravity-Style Bot Adjuster: An interactive draggable splitter that allows seamless real-time resizing, minimizing, and expanding of the witness interview bot and the 3D studio.
  • Cross-Platform Platform Bridge: Eliminates web-only compilation crashes on Android phones by dispatching between platform_bridge_web.dart on Web and platform_bridge_stub.dart on mobile.
  • Obsidian & Cyber Teal Theme: Unified aesthetic across all screens using deep obsidian (#090D14, #101520) and luminous cyber hacker teal (#00BFA5, #2DD4BF).

4. Execution Commands

# 1. Start Python FastAPI Backend:
cd backend
python -m uvicorn app:app --host 127.0.0.1 --port 8000 --reload

# 2. Run Flutter Web Studio:
flutter run -d chrome

# 3. Build / Run Android Phone APK:
flutter run
# Or generate debug APK:
flutter build apk --debug
